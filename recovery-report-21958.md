## Content covered by the recovered 49 posts

Framing and canopy (2019-09), the oar mechanism / section model and machinery, hull planking
(holm oak frames, lime planking), thole pins and thalmian beams, seats and stretchers,
oar fabrication and statistics, deck / structure, painting. The final pages (6–9) covered
completion of the 62 oars (tapering, fitting, statistics), paint trials, and waterproofing —
recoverable only as the 8 profile snippets.

## Gaps and limitations

1. **Pages 6–9 (post #126 onward) are unrecoverable in full.** Wayback never captured them
   under any URL variant tested: `/topic/21958-*`, `/page/6/`…`/page/9/`,
   old `index.php/topic/21958`, wildcard `topic/21958*`, print/RSS views. Only 8 partial
   snippets survive via the profile activity stream (comment IDs 1103343, 1103684, 1103809,
   1104002, 1105024, 1105134, 1106198, 1106329).
2. **37 of 52 images are lost** — no Wayback capture exists and the current site's CDN
   (`modelshipworld.com/uploads/...`) returns HTTP 404 for the old thread's attachments.
3. Forum "replies" count (264) exceeds the 126 posts recovered, consistent with the missing
   later pages.
4. Snapshot gaps: no page captures between 2019 and 2021; many snapshots are of the index/topic
   listing rather than the thread itself.

## Method

- CDX inventory queries against the Wayback API for the topic, its pages, member profile,
  and image monthly-upload directories; all manifests saved in
  `/tmp/opencode/wayback/manifests/`.
- Fetch of raw HTML via `id_` suffix to avoid Wayback banner injection.
- Posts parsed from IPB `<article id="elComment_…">` blocks with a stdlib regex extractor
  (`extract_t21958.py`), merged and deduplicated by comment ID (`assemble_t21958.py`),
  filtered to Richard Braithwaite (49 posts).
- Image recovery resolved per-URL against Wayback (`lookup_images*.py`,
  `image_archive_map.json`); archived copies linked with `…id_/` raw URLs.
- Profile snippets parsed from the archived profile activity stream (`parse_profile.py`).
- Output generated by `generate_md.py`.
